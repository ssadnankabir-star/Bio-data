Sadnan Kaabeer - High Quality Bengali PDF / Image Export

Upload the files in this package to the same GitHub Pages repository.

Important changes:
- Professional PDF is NOT built from jsPDF text anymore.
- Each PDF page is rendered by the browser from the live website layout, so Bangla fonts render exactly as they do on the website.
- PDF uses high-resolution PNG pages for sharper text and design.
- Clickable web links are overlaid onto the PDF after rendering, including profile photo, social links, gallery, email, phone/WhatsApp and portfolio links.
- The same three complete page layouts are used for image sharing.
- No section is intentionally split between image pages.

Required files:
- index.html
- js/live-export.js
- assets/profile.jpg
- your existing admin/config files from the repository

The page needs internet access to load html2canvas/jsPDF from jsDelivr, just like the current site already does.
